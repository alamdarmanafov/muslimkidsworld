# Muslim Kids World 🌙

Expo + React Native starter UI for Muslim Kids World.

## Run
1. Install Node.js.
2. Run `npm install`.
3. Run `npx expo start`.
4. Scan the QR code with Expo Go, or use `npm run ios`, `npm run android`, or `npm run web`.

## Current screens
- Welcome / Parent or Child selection
- Parent dashboard
- Family Code
- Child code entry
- Child home
- Premium Family

This is a UI prototype. Authentication, real Family Code validation, subscriptions, database, parental controls, and App Store/Google Play billing should be connected before production.
