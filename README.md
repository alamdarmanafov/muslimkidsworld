# Muslim Kids World 🌙

**Learn • Play • Grow**

Muslim Kids World is a global, family-oriented Islamic learning platform for
children, built around two products that share one backend:

- **📱 Mobile App** — a Parent experience (account, subscription, child
  management, progress tracking) and a Child experience (daily lessons,
  quizzes, games, a virtual world, and rewards).
- **🖥️ Admin Dashboard** — internal tooling for managing users, content,
  subscriptions, localization, and analytics across the whole platform.

The guiding principle: **parents pay, children play, admins run the system.**
